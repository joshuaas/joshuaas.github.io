# 添加课程资源

将 PDF 放到对应章节和类型目录中，Jekyll 在每次构建时自动更新大纲中的课件、板书下载入口。无需逐个修改 YAML，也无需修改 GitHub Actions。

```text
assets/teaching/
├── 01/
│   ├── slides/          # 第一章课件
│   │   └── 第一章 绪论.pdf
│   └── board_notes/     # 第一章板书
│       └── 第一章 板书.pdf
├── 02/
│   ├── slides/
│   │   ├── 01 向量.pdf
│   │   └── 02 矩阵.pdf
│   └── board_notes/
└── …                   # 03–10 使用同样的结构
```

| 目录 | 章节 |
| --- | --- |
| `01` | 绪论 |
| `02` | 线性代数复习 |
| `03` | 概率统计复习 |
| `04` | 回归 |
| `05` | 分类 |
| `06` | 深度神经网络 |
| `07` | 间隔理论 |
| `08` | 模型集成 |
| `09` | 聚类 |
| `10` | 表征、重构及生成模型 |

- `slides` 为课件，`board_notes` 为板书。同一章、同一类型可以放多个文件，也可以只放板书。
- 页面标题使用不含扩展名的文件名；中文、空格和 `.PDF` 大写扩展名均可。下载时保留原文件名。
- 文件按名称自然排序，例如 `01 内容.pdf`、`02 内容.pdf`、`10 内容.pdf`。
- PDF 直接放在类型目录下，不再嵌套子目录。未知章节或类型目录中的 PDF 会在构建日志中提示并跳过。
- 构建仅检查文件路径，不解析 PDF 内容，支持加密 PDF。
- 移除或改名自动目录中的 PDF 后，下一次构建会相应移除或更新链接。未上传文件的章节只显示章节标题。

当前资源已使用自动目录。若需要自定义显示标题、下载文件名，或链接自动目录以外的文件，仍可在 `_data/teaching.yml` 中对应章节添加手动配置，例如：

```yaml
resources:
  slides:
    - title: 自定义标题
      file: /assets/teaching/01/slides/第一章 绪论.pdf
      download_name: introduction.pdf
  board_notes: []
```

同一路径同时被自动发现和手动登记时，优先使用手动配置，页面不会重复列出。手动配置的文件改名或删除时，也需要更新或删除相应配置。

本地使用 `bundle exec jekyll serve` 时，新增或移除文件会触发重建；刚添加此插件时，需要重启本地服务以加载插件。线上只在将文件提交并推送到触发现有 GitHub Actions 的分支后更新，本地放入文件不会直接修改线上网站。

检查自动资源收集：

```sh
bundle exec ruby bin/test-teaching-resources.rb
```
